Glamorous and editorial. The Didone/Garalde pairing spans three centuries — elegant, but historically loose.
Display & text
Old Standard TT — revival of the late-19th-century “Modern” roman used in scientific journals and encyclopaedias
Labels
Oswald 500 / 400 · tracking .12em — a condensed gothic in the wood-type tradition
Character
The most period-true: one family carries everything, like a real Victorian technical volume. Fewer weights; small caps are synthesised.
Display & text
Source Serif 4 — Fournier-influenced transitional with real optical sizes (8–60 pt)
Labels
IBM Plex Sans Condensed 600 / 500 · tracking .10em — engineered, instrument-panel grotesque
Character
Leans toward “modern precision dashboard”. Calmest in dense data and in Night; least antique.

Recommendation to testClassic for almanac and editorial pages, Precision for data-dense instrument panels, or Scotch everywhere for maximum period character. Open the examples and cycle the type switch to judge them in context — that is where the differences become decisive.

Numerals

§ 2.3

In prose — old-style, proportional

Founded 1847; 315 leaves; 2,048 pixels.

Applied automatically to .em p. Old-style figures sit in the lower-case like text — the book convention.

In data — lining, tabular

  • Well depth150 000 e⁻
  • Read noise2.01 e⁻
  • Gain2.20 e⁻/ADU

Labels, metrics, tables, scales and dials use lining-nums tabular-nums so columns align. Add .em-num anywhere else.

Production imports

§ 2.4

The exploration stylesheet imports all seven families. Once a set is chosen, replace the @import in em.css with one of these and add the matching class to the root.

/* A · Classic  (default; no class needed) */
@import url('https://fonts.googleapis.com/css2?family=Barlow+Condensed:wght@500;600;700&family=Bodoni+Moda:ital,opsz,wght@0,6..96,400..900;1,6..96,400..700&family=EB+Garamond:ital,wght@0,400..700;1,400..600&display=swap');

/* B · Scotch   (class="em em--type-scotch") */
@import url('https://fonts.googleapis.com/css2?family=Old+Standard+TT:ital,wght@0,400;0,700;1,400&family=Oswald:wght@400;500;600&display=swap');

/* C · Precision (class="em em--type-precision") */
@import url('https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Condensed:wght@400;500;600&family=Source+Serif+4:ital,opsz,wght@0,8..60,300..700;1,8..60,300..600&display=swap');
